# Mysa Thermostat Compatibility Checker - Technical Overview

## Purpose

The Mysa Thermostat Compatibility Checker is a mobile web application designed to help users determine if their current thermostat setup is compatible with Mysa smart thermostats. It guides users through a step-by-step process of capturing information about their existing thermostat and wiring, analyzes this information, and provides a compatibility result.

## Technology Stack

- **Framework**: Next.js 13+ with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Custom components built on top of shadcn/ui
- **State Management**: React Hooks (useState, useEffect)
- **Routing**: Next.js App Router
- **Image Optimization**: Next.js Image component
- **Icons**: Lucide React
